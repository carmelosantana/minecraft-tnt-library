# F-Bomb Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the isolated `org.xpfarm.tntlibrary.fbomb` logic package — a "menace then blast" fake-Wither cinematic (BlockDisplay+Interaction rig, BossBar, telegraphed WitherSkull volley, signature blast, full teardown) — plus its headless tests, with **zero edits to any shared file**.

**Architecture:** Mirror the Phase 2 isolation split (smartbomb/twins) and the `tuesday-twister` fake-boss reference. A pure, headless-testable core (params, config reader, spawn-placement direction/offset math, cinematic state machine, skull-volley schedule) is wrapped by a thin Bukkit edge (CustomTnt item, display rig, tagged-TNTPrimed blast, per-show state machine, single-`runTaskTimer` director, feature module). Igniting a placed F-Bomb will be diverted by the **orchestrator** (in the shared `IgnitionListener.ignite()`) to `plugin.fBomb().director().summon(block, igniter)` — exactly like the SmartBomb `arm` divert — so this package needs only to expose that entry point and compile standalone against existing shared types.

**Tech Stack:** Java 25, Paper 26.1.2 API (`BlockDisplay`, `Interaction`, `BossBar`, `WitherSkull`, `TNTPrimed`), JUnit 5 (junit-jupiter), Maven (group `org.xpfarm`).

> **Design decision (orchestrator-settled 2026-08-25):** there is **no WorldSnapshot / SnapshotCodec / air-pocket carve** — a display-only apparition replaces no world blocks, so the tuesday-twister terrain-restore subsystem does not apply. BlockDisplay entities render through solid blocks, so partial embedding is a purely cosmetic ~3-second edge case. "No orphaned entities ever, including a mid-cinematic server stop" is satisfied entirely by the PDC-tagged (`fbomb_rig`) entity orphan-sweep on enable + `endAll()` on disable — keep that airtight. The freed effort goes into a smarter `SpawnPlacement` that biases the apparition toward open air above the blast.

### Task 3: SpawnPlacement — pure open-air direction choice + rig offset

**Files:**
- Create: `src/main/java/org/xpfarm/tntlibrary/fbomb/SpawnPlacement.java`
- Test: `src/test/java/org/xpfarm/tntlibrary/fbomb/SpawnPlacementTest.java`

**Interfaces:**
- Produces:
  - `static final float[] DIRECTION_YAWS = {0f, 45f, 90f, 135f, 180f, 225f, 270f, 315f}` — the eight candidate horizontal headings the air-probe scores (Bukkit yaw `y` maps to heading `(-sin y, 0, cos y)`).
  - `static int chooseBestDirection(double[] openness, int preferredIndex)` — the index of the direction with the greatest openness score. Ties resolve toward `preferredIndex` when it is in range and achieves the max; otherwise the lowest index achieving the max. `openness.length` must equal `DIRECTION_YAWS.length`.
  - `static Location offset(Location origin, double yawDegrees, double distance, double height)` — moves `origin` `distance` blocks along heading `yawDegrees` and `height` up; returns a clone (origin never mutated), keeping world + facing.

Pure, world-independent math; `org.bukkit.Location` is a plain API data class constructable headless as `new Location(null, x, y, z, yaw, pitch)`, so this is unit-tested directly. The Bukkit air-probe that *builds* the `openness` array lives in the director (Task 8), not here.

Semantics (models the `GrowthModel.phaseFor` pure-fn pattern). Precondition (guaranteed by the `menace-ticks` clamp floor of 20 > `SUMMON_TICKS`): `menaceTicks > SUMMON_TICKS`.

- [ ] **Step 1: Write `FBombShow.java`** — AGPL header. Hold a `boolean finished` and a `boolean toreDown` guard. `tick(long tick)`:
  1. If `sourceBlock` is no longer an F-Bomb (`BombBlocks.bombIdOf(sourceBlock).map(FBomb.ID::equals).orElse(false)` is false — broken mid-show), `teardown()`, set `finished = true`, return **without detonating** (abort-silently, mirroring `BombFuse`/`SmartBombWatcher`).
  2. `CinematicPhase phase = CinematicStateMachine.phaseAt(tick, params.menaceTicks())`.
  3. `SUMMON` (tick 0 only): play `world.playSound(rigCenter, Sound.ENTITY_WITHER_SPAWN, 4f, 0.6f)`; add in-range players to the boss bar. (The rig was already spawned by the director.) Also `rig.animate` each SUMMON tick for the fade bob.
  4. `MENACE`: `rig.animate(rigCenter, tick)`; `updateBossBar` — `bossBar.setProgress(1.0 - (tick / (double) params.menaceTicks()))` clamped to `[0,1]`, title "F-Bomb", manage viewers by `params.bossbarRange()` (add players in range/world, remove those out — mirror `WitherStorm.manageViewers`); if `SkullVolleySchedule.firesAt(tick, params.skullCount(), params.skullCadenceTicks(), CinematicStateMachine.SUMMON_TICKS, params.menaceTicks())`, fire one telegraphed `WitherSkull` from `rigCenter` toward the nearest boss-bar viewer (normalize direction, `setVelocity(dir * ~1.0)`, modest `setYield`, `setIsIncendiary(false)`, tag with the show id) — survivable.

  `finished()` returns the flag. `teardown()` guards on `toreDown`.
